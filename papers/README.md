# FORGE — Research Literature & Papers Index

This directory contains full-text academic papers supporting the FORGE FYP project, organized into two dedicated subdirectories:

1. **[`pcgrl_and_foundations/`](./pcgrl_and_foundations/)**: Contains the foundational papers for Procedural Content Generation via Reinforcement Learning (PCGRL), Multi-Objective PCG, Explainable AI (SHAP & TreeSHAP), and Flow / Measurement Theory.
2. **[`dynamic_difficulty_adjustment/`](./dynamic_difficulty_adjustment/)**: Contains papers specifically addressing Dynamic Difficulty Adjustment (DDA), reinforcement learning encounter balancing, empirical player modeling, and psychometric evaluation instruments.
