\section{Work Completed}
Up to Final-1 (Weeks 1--14) the team completed:
\begin{itemize}
    \item \textbf{Research:} a structured review of 40 sources on DDA, PCGRL, flow and player-experience measures.
    \item \textbf{Game:} a 2D action roguelike in Godot 4.7 with sword combat, dodge roll, five enemy archetypes, animated pixel art, camera shake, damage numbers, minimap, pause menu, consent screen and per-floor rating.
    \item \textbf{Generation and adaptation:} a two-stage generator (connected layout, then PPO-driven content), five calibration floors with $CR_0$, an 8-output PPO policy running in GDScript with a heuristic fallback, and the static $+8\%$ baseline.
    \item \textbf{ML:} simulator v3 and a policy retrained on it (3 seeds $\times$ 1M steps), an offline LightGBM Judge with TreeSHAP and Design Insight Reports.
    \item \textbf{Data and CI:} SQLite telemetry with migrations and a JSON fallback; GitHub Actions with ruff, \texttt{pytest}, policy-file checks, 11 headless GDScript tests, a real-SQLite test, the 3,500-layout harness and a Windows export smoke test.
\end{itemize}

\section{Current Limitations}
\label{sec:limitations}
\begin{enumerate}
    \item \textbf{All PPO evidence is simulated.} No comparison with humans exists yet.
    \item \textbf{Real data is one player} (29 floors). Every real-data result is a pilot.
    \item \textbf{The Judge is trained on synthetic data} and does not beat the old formula on the real floors. It runs offline only; the game still uses the linear score.
    \item \textbf{Part of the personalisation is in the reward,} which uses the simulated player's hidden skill, reflex and tactics.
    \item \textbf{Simulator and game still differ:} heal size (18\% of max HP vs.\ 35\,HP), the apex champion is not simulated, hazard damage is modelled differently, and the cold-start observation is averaged differently.
    \item \textbf{The observation is the last floor only,} and the policy does not see four of the settings it controls.
    \item \textbf{No BSP baseline yet,} and the static baseline is weak.
    \item \textbf{Calibration floors confound comparisons} unless all conditions get the same first five floors.
    \item \textbf{Telemetry is logged without consent} (flagged and excluded); consent is asked at first launch, not after Play.
    \item \textbf{The minimap may make floors too easy;} hiding it in the playtest build is planned.
\end{enumerate}
