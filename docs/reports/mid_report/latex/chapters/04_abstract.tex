\chapter*{Abstract}
\addcontentsline{toc}{chapter}{Abstract}

Procedural Content Generation (PCG) in video games has largely transitioned from brittle rule-based grammars to learned policies via Reinforcement Learning (PCGRL). However, prevailing PCGRL frameworks synthesize environments conditioned on static designer-authored target vectors or optimize for an aggregate average player, ignoring individual differences in motor skill, risk tolerance, and combat pacing. Concurrently, conventional Dynamic Difficulty Adjustment (DDA) mechanisms rely on simplistic, reactive scalar multipliers that frequently trigger perceptible rubber-banding and break player immersion.

This project presents \textbf{FORGE} (\textit{Personalized Procedural Content Generation via Reinforcement Learning}), an end-to-end, closed-loop adaptive dungeon synthesizer developed in the Godot 4.x engine for 2D top-down combat roguelikes. FORGE continuously profiles in-session gameplay telemetry (clearing time, death count, and damage taken) which, with the current difficulty settings and run depth, forms the 8-dimensional input of a Proximal Policy Optimization (PPO) policy. The policy outputs a structured 7-dimensional combat difficulty action vector controlling continuous enemy attributes (health, damage, speed, aggro radius), environmental hazard density, resource scarcity, and room count. To avoid external runtime dependencies on player machines, FORGE couples an offline Python training pipeline (Gymnasium, Stable-Baselines3) with an embedded pure-GDScript neural network forward pass that runs once per floor in well under 1\,ms (median about $0.2$--$0.4$\,ms). 

To overcome initial cold-start volatility, FORGE introduces a 5-floor weighted calibration protocol that summarizes the player as a combat rating ($CR_0$) and seeds the policy's first observation from the same calibration records before closed-loop adaptation activates. For the FYP-1 Mid-Term Evaluation, the project team implemented and verified: (1) cohesive pixel-art dungeon aesthetics, trauma-decay camera shake, and color-coded floating combat text; (2) multi-archetype combat dynamics featuring Melee Crawlers and Ranged Pyromancers with telegraphed fireball projectiles alongside a player invulnerability dodge roll; (3) a live telemetry defense overlay with a deterministic static roguelike baseline toggle; and (4) an automated headless Godot continuous integration (CI) pipeline with a start-to-exit reachability regression test over 3,500 seeded layouts and headless tests of telemetry capture and cold-start calibration. Simulation shows the trained policy outperforms an untrained network on simulated player profiles, while also revealing that it currently personalizes only part of the 7-dimensional action space; retraining against a corrected simulator and validation with human players are planned. The prototype thus demonstrates the feasibility, but not yet the benefit, of personalized closed-loop difficulty generation.
